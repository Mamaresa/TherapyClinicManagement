# What this document is not

This is a schema design specification, not applied DDL and not application code. No file was edited. No Django model, migration, SQL, or implementation code was created. No schema has been applied to any database. Triggers are specified (Section 14.2 in the source, which is [trigger summary](../03-enforcement/triggers/README.md)), not written. Extension installation (btree_gist) is documented as a deployment prerequisite.

The next stage, per the Operator, is implementation planning, which requires a separate authorization.
